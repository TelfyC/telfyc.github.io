## 项目经历

### 未界智联 | 前端开发 | 2024.06 - 至今

**项目简介：** 面向工业用户的 IoT 设备管理 App，支持通过蓝牙 BLE 连接智能硬件，实现设备发现、网络配置、数据采集、固件升级与组织管理等功能。

**技术栈：** React Native、BLE、KCP、OTA

**核心工作：**

1. 在 BLE MTU 分包限制下，完成 **KCP ARQ 可靠传输协议** 的 JavaScript 移植，保障蓝牙链路下的大数据稳定传输。
2. 设计多信道 BLE 通信架构，基于会话 ID 实现多路数据流并发，支撑设备控制、数据采集等复杂并发场景。
3. 实现完整 OTA 固件升级方案，覆盖 CRC32 校验、分片传输、断点续传与状态机进度管理，完善升级稳定性与过程可控性。

**项目成果：**

1. 引入 **KCP ARQ 可靠传输层** 后，将 **500KB 固件** 在 BLE 信道下的 OTA 传输成功率从 **20% 提升至 99.99%**。
2. 通过多路 KCP 信道架构设计，解决设备控制与设备采集无法同时触发的业务痛点，提升复杂设备交互场景下的稳定性与可用性。
